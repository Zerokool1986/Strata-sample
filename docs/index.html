The failure mode

The problem is reuse, not storage

Storing what an agent learns is easy — every tool stores. Memory fails later, at the moment of reuse, when the agent reaches for a piece of knowledge and can't tell whether it's proven, guessed, stale, or dead.

Your agent learns something in week one: "refunds go through processor X." In week six, the project switches processors. The old fact is still sitting in the store, retrieved by similarity, stated with confidence. The agent rebuilds the refund flow on a dead premise.

A memory system that only ever adds guarantees its oldest mistakes stay load-bearing forever. Retrieval fixes recall. It does not fix truth.

Strata is built mechanism by mechanism against the four failures you actually pay for: the disproven approach quietly resurrected because nothing marked it dead; the contradiction averaged away by a summary; the dependent conclusion still standing weeks after its premise collapsed; the careless entry filed at full confidence during a busy task.

How it works

Four rules govern every layer

Entries are typed, statused, and sourced — and when knowledge is disproven, a new layer covers it. The old one stays readable underneath. These rules are the difference between Strata and a folder of notes:

1. Status travels

An entry's standing — settled, assumed, disproven, rejected — is part of the entry and rides into every context it's quoted in. Nothing gets promoted by being repeated.

2. Two clocks

When a thing became true and when you learned it are separate fields. "What did we believe in March?" is a question Strata can answer.

3. Buried, not deleted

Superseded and disproven entries stay on the record with validity closed. Negative knowledge — what already failed, and why — is the most valuable stratum in the system, and it is never erased.

4. Not everything earns a layer

Sources are tiered. Material from untrusted sources can wait in an inbox, but it cannot harden into knowledge until it's corroborated. Text inside a source is data, never instructions.

The proof

Tested end-to-end before it was sold

Strata was pulled from its repo, installed into a fresh project by its own quickstart, exercised — entries filed, an assumption superseded, the invalidation sweep run (the one dependent entry was flagged, exactly as designed) — and then a fresh agent session was given the system's own eight-question self-test against the worked example: recall, update, temporal reasoning, multi-hop, contradiction, provenance, plus two traps — a question with no answer in the store (correct move: abstain) and a question built on a false premise (correct move: correct the premise first).

Honest limits: the agent that answered was the same model class that built the test store; the example store is curated; three harder probes from the full test were not run. FAQ

Straight answers

Is this software? Do I install anything?

No. Strata is a zip of Markdown templates, folder structure, and short guides. You copy it into a repo and use it with Git and whatever agent you already use. There is no Strata service — no account, no sync, no dashboard.

Which agents does it work with?

Any agent that can read and write files in a repo — Claude Code, Codex, Cursor, and similar tools. Nothing is tied to one vendor; the store is plain Markdown with an AGENTS.md template covering the common instruction-file convention.

Isn't the base pattern free? Why pay?

Yes — the base pattern is Andrej Karpathy's LLM Wiki idea, published free and credited everywhere in the kit; you can absolutely implement it yourself. What you pay for is the finished system the pattern doesn't ship: the category set, the status lifecycle, supersession and invalidation machinery, the trust gate, the consolidation discipline, two self-tests, and the worked examples — 113 files of design you don't have to invent. DIY costs design time; Strata costs $14.99–$44.99, once.

Can I use it in commercial projects?

Yes — your own projects, including commercial and client work. You may not resell or redistribute Strata itself as a product.

What does it not do?

It will not make an agent smarter, and it isn't automation. Your agent still writes the entries; Strata gives that knowledge a durable, honest shape. Results depend on actually filing entries and keeping statuses honest. No income, productivity, or outcome guarantees are made or implied.
